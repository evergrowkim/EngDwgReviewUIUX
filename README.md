# doAZ Drawing Review UI/UX v1.2

This package contains the v1.2 drawing review UX standard and interactive prototype.

## Files
- `doAZ_Drawing_Review_Claude_Code_Guide_v1.2.md` — UI/UX and implementation guide
- `doAZ_Drawing_Review_UX_Lab_v1.2.html` — interactive prototype
- `doAZ_Drawing_Review_UX_Lab_v1.2_preview.png` — prototype preview
- `doAZ_Drawing_Review_UX_v1.2_Package.zip` — bundled package

## v1.2 highlights
- Navigator / Review / Issues / Layers information architecture
- Spatial drawing canvas as the primary work surface
- Context inspector with evidence-first review flow
- Bottom review data grid for high-volume review
- Evidence comparison separated from revision comparison
- Layer manager and semantic zoom foundations
- Resume review / issue workflow / review state separation
- Multi-window and dual-monitor review principles retained from v1.1
